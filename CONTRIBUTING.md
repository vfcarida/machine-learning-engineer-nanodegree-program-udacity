# Contributing to ML Nanodegree Portfolio

Thank you for your interest in contributing to this project! To maintain the quality and professional standards of this repository, please follow these guidelines.

## 🛠️ Development Workflow

1. **Fork the Repository**: Create your own copy of the project.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Write Clean Code**:
   - Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/) style guidelines.
   - Use type hints for all function signatures.
   - Add docstrings in Google style.
4. **Run Tests**:
   Ensure all tests pass before submitting a PR:
   ```bash
   pytest
   ```
5. **Commit Your Changes**:
   Use descriptive commit messages:
   ```bash
   git commit -m "feat: add feature importance plotting to feature_selector"
   ```
6. **Push and Open a PR**: Submit your changes for review.

## 📝 Standards

- **Static Analysis**: We use `flake8` for linting and `mypy` for type checking.
- **Documentation**: Any new feature must be documented in the relevant project's README.
- **Jupyter Notebooks**: Please clear all cell outputs before committing notebooks to keep the repository size manageable.

## 🐛 Reporting Issues

If you find a bug or have a suggestion, please open an issue with:
- A clear description of the problem.
- Steps to reproduce (if applicable).
- Expected behavior.
